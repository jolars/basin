# Robust-loss LM/TRF analytic measurement pilot

The [manifest](2026-10-09-robust-ls-001.toml) and [retained
report](../robust-ls-results.json) record 352 deterministic solves in both
native precisions. Source and planned manifest commit `f0c6d05` preceded
execution. Verifier-only corrections and continuation checks are frozen in
`68c6a28`. The solver source and original solve CSVs remain unchanged throughout
the run. No default, safeguard, calibration policy, or holdout outcome changed.

## Scope and references

The runner uses the production `RobustLeastSquares` adapter with analytic raw
residuals. Four LM routes cross normal equations and pivoted QR with Nielsen and
trust-region damping. Legacy `Trf` and full `TrustRegionReflective` complete the
six unconstrained routes. The robust bound case runs only the two TRF routes.
All raw fixtures are one-dimensional and use nalgebra 0.34.

  | Fixture                    | Raw residuals | Loss and scale | Start | Known minimum |
  | -------------------------- | ------------- | -------------- | ----- | ------------- |
  | Huber outlier              | `(x,x,x-8)`   | Huber, 1       | 0.1   | 0.5           |
  | Huber rescaling            | `(x,x,x-8)`   | Huber, 0.5     | 0.1   | 0.25          |
  | Symmetric smooth loss      | `(x-2,x+2)`   | Soft-L1, 1     | 0.1   | 0             |
  | Negative initial curvature | `x-1`         | Cauchy, 1      | -1    | 1             |
  | Huber transition           | `x-1`         | Huber, 0.5     | 0.5   | 1             |
  | Non-finite trial domain    | `1+(x-1)²`    | Soft-L1, 1     | 0.1   | 1             |
  | Active robust bound        | `(x,x,x-8)`   | Huber, 0.5     | 0.1   | 0.125         |

For the last case, bounds are `[0,0.125]`. The robust gradient at its optimum is
-0.25, so the reference satisfies the upper-bound KKT condition without a zero
raw gradient. The non-finite fixture returns NaN outside `[0,1.1]`, using the
native-precision representation of its domain constant.

The Huber objectives are convex, and their derivative near the unconstrained
minimum is `2*x-scale`, giving `x=scale/2`. Strict convexity establishes the
symmetric soft-L1 minimum. The single-residual Cauchy and Huber losses increase
with absolute residual, giving `x=1`; the non-finite fixture's finite objective
also has its unique minimum there. These are analytic references, not fitted
outputs from Basin or a competitor.

Each default case runs with physical caps 0, 1, 2, and 4000. Unconstrained LM
cases additionally run one explicit relative probe at cap 4000, with absolute
gradient tolerance zero and robust orthogonality, model reduction, trial step,
and trust radius tolerances `1e-8` for `f64` or `1e-4` for `f32`. Radius tests
apply only to trust-region damping. These settings exercise measurement and are
not recommended policies. The checker labels robust orthogonality separately
from ordinary residual orthogonality.

## Independent verification

The checker independently evaluates loss values, derivatives, and curvatures
with 100-digit Decimal arithmetic. It checks published and trial objectives, raw
robust gradients, safeguarded model diagonals, undamped robust model
predictions, actual reductions, acceptance, full-TRF radius updates, stopping
operands, and publication boundaries. Negative and zero residual curvature uses
the production model's precision-specific epsilon floor, while the objective and
robust gradient retain the actual loss derivatives.

The returned quality record contains the analytic objective gap, parameter
error, gradient, and projected KKT residual. Default measurement checks require
parameter and stationarity errors below `1e-6` in `f64` or `1e-3` in `f32`.
Relative-probe measurement checks use `1e-4` or `2e-2`, respectively. These
unit-scale checks do not certify CDP-1 corpus target eligibility or select
convergence tolerances. Poor results remain in the report. Errors have no
returned quality record; their last published points are assessed separately.

For every relative probe, the checker compares callback kinds, points, and
outcomes with the default route's common prefix. The shorter run need not be the
probe: an exact default gradient stop can precede a zero-tolerance probe. Paired
default outcomes, work, final quality, and available objective improvement are
retained separately.

## Findings

There are 38 unrestricted default cases per precision. All 38 `f64` cases
converge and pass measurement quality. The `f32` defaults have 16 convergence
outcomes, 18 stalls, and four callback errors at the physical budget. All 34
returned points pass the measurement quality checks. All four budget-error cases
also have good last published points, but acquire no returned point.

The four budget errors belong to legacy TRF: Huber at both scales, symmetric
soft-L1, and the non-finite domain fixture. Damping reaches infinity and
produces 15,894 non-finite predictions across those runs. The native safeguarded
ratio rejects these trials, but the runs continue until the next callback is
denied at cap 4000. This exposes a remaining finite-model/no-progress safeguard
gate; it is not convergence evidence or a reason to relabel errors as success.

All 48 relative probes report convergence, but four fail independent quality:
normal-equation and pivoted-QR Nielsen LM on Cauchy, in both precisions. Both
model reduction and trial step pass on a tiny accepted, published step under
large damping, despite a substantial robust gradient:

  | Precision                  | Probe work | Parameter error | Gradient magnitude | Default work | Default parameter error |
  | -------------------------- | ---------- | --------------- | ------------------ | ------------ | ----------------------- |
  | `f64`, both factorizations | 21         | 0.9503          | 0.4994             | 96           | `7.63e-11`              |
  | `f32`, both factorizations | 18         | 0.2445          | 0.2307             | 55           | 0                       |

The paired default traces have exactly the same callbacks through each probe's
stop and then reach the analytic minimum. Available objective improvement is
about 0.32174 in `f64` and 0.02903 in `f32`. This establishes premature stopping
for these explicit probe settings on this fixture. It supports a robustness
review of optional step/model-reduction composition; it does not select a
replacement policy or imply the absolute-gradient default stops prematurely.

Across all 352 cases, outcomes are 102 convergences, 18 stalls, 76
initialization errors, and 156 callback errors. The physical ledger records
18,069 calls: 276 fused initializations, 17,131 residual calls, and 662 Jacobian
calls. There are 232 denials, including the 76 initialization denials whose
logical counters are unavailable. Authoritative counts reconcile per run.
Objectives computed from residuals consume no cost callback or logical cost
request. Native traces retain 17,231 attempted trials, including 100 budget
denials, 738 acceptances, 16,393 rejections, 86 non-finite trial objectives, and
724 publications. Fourteen accepted trials denied their Jacobian remain
unpublished.

## Corrections, validation, and remaining work

The first independent prediction check omitted absolute residual-gradient terms
involved in QR cancellation. The fixed 4096-unit-roundoff allowance now includes
those terms, alongside the existing damped squared-step underflow allowance and
four smallest subnormals for rounded scalar products. Regression checks cover
both cancellation and subnormal rounding. Non-finite predictions are retained as
non-finite and must be rejected, rather than treated as finite model identities.
The checker still verifies their native safeguarded ratios, trial costs,
accounting, and publication behavior.

A corrupted-prediction control initially altered a pending denied trial, whose
prediction had no completed residual decision. It now alters a completed trial.
The final 12 Python tests pass with 12 corrupted-record controls on robust
traces. They also pass with the original analytic and bounded pilot traces. All
29 Rust measurement tests pass on nalgebra 0.34 and 0.35. Workspace
all-target/all-feature clippy with warnings denied, Rust formatting,
documentation formatting/lint, local links, and manifest hashes pass. No core
numerical code changed, so this run does not require a new WASM or public API
build.

Step 5 remains open. This covers three built-in robust losses on small analytic
nalgebra fixtures. Arctangent and custom losses, larger/rank-deficient problems,
fixed robust coordinates, other backends, finite differences, transformed corpus
cases, precision eligibility certificates, and complete inner-work accounting
retain their gates. Next, investigate the legacy TRF finite-model and
no-progress behavior and assess robust step/model-reduction composition before
an affected candidate sweep. Preserve these traces as controls.
