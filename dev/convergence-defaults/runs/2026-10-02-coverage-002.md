# Expanded coverage pilot, October 2, 2026

This baseline pilot verifies the expanded fixtures and recorder. It contains
**844 solves across 14 solver names**, with native `f32` and `f64` evaluation.
All solved cases belong to development families. Validation families have only
reference and derivative tests; they have not been optimized. No target grid,
precision floor, or numerical default was selected.

The [manifest](2026-10-02-coverage-002.toml) records exact commands, inputs,
budgets, compiler, features, and output hashes. The [source
hashes](2026-10-02-coverage-002.sources.sha256) cover the fixture and runner
sources, Cargo inputs, and all 27 original NIST data files. Raw CSV traces are
under `target/convergence-defaults/2026-10-02-coverage-002/`. Regenerating them
changes elapsed times and therefore output hashes.

## Cases and settings

The [coverage matrix](../coverage.md) describes 57 fixture definitions and the
remaining solver and stratum gaps. Reviewable generated lists contain the [50
vector definitions](../cases.csv), [four root definitions](../scalar-roots.csv),
and [three scalar minima](../scalar-minima.csv). Scalar lists include a row for
each precision. Reserved definitions are listed but excluded from the pilot.

  | Suite                  | Development definitions               | Solves | Recorded rows |
  | ---------------------- | ------------------------------------: | -----: | ------------: |
  | NIST                   |                              16 of 27 |    256 |        29,054 |
  | Analytic least squares |                                    15 |    240 |        16,713 |
  | Constrained            |                                6 of 8 |     24 |           272 |
  | Stochastic             | Three noisy analytic controls, reused |    240 |        48,480 |
  | Scalar roots           |                                3 of 4 |     60 |            60 |
  | Scalar minima          |                                2 of 3 |     24 |           776 |

Every definition uses two starts or intervals and both precisions. NIST and
analytic cases run Nelder–Mead, L-BFGS-B, LM, and full TRF. Constrained cases
run SLSQP. Scalar cases run all five root solvers and all three minimizers. SGD
uses learning rate `0.02`, batch size one, and seeds `0..19` paired across
starts and precisions. Other algorithm settings use constructor defaults.

Optimization has a 200-iteration safety cap and a 2,000-pass boundary budget.
Root finders retain their default 100-iteration budgets. The largest recorded
pass count is 2,016 in a constrained solve: the harness preserves the final
step's overshoot. Minibatch gradients charge the full derivative model pass they
actually evaluate. Callback categories remain separate.

Unlike the first Misra1a pilot, the NIST cases have no added finite bounds.
Their L-BFGS-B and TRF interfaces receive infinite bounds. Results from the two
pilots therefore should not be treated as a controlled code comparison.

## Observations

  | Suite       | Stop counts                                                                                                      |
  | ----------- | ---------------------------------------------------------------------------------------------------------------- |
  | NIST        | 125 `MaxIter`, 55 `NumericalNoProgress`, 41 `SolverFailed`, 30 `SolverConverged`, 5 `ProjectedGradientTolerance` |
  | Analytic    | 97 `SolverConverged`, 71 `MaxIter`, 41 `ProjectedGradientTolerance`, 18 `NumericalNoProgress`, 13 `SolverFailed` |
  | Constrained | 21 `SolverConverged`, 2 `HarnessPassBudget`, 1 `SolverFailed`                                                    |
  | Stochastic  | 240 `MaxIter`                                                                                                    |
  | Roots       | 56 `Converged`, 4 `MaxIter`                                                                                      |
  | Minima      | 23 `SolverConverged`, 1 `MaxIter`                                                                                |

These are termination counts, not success rates. In the constrained `f32` cases,
the disk and scaled ellipse expose small feasibility errors at budget or failure
stops. The largest root position error is approximately `1.2e-7`, even though
four runs report an iteration limit. SGD's iteration-limit stops are consistent
with its budget-driven default. Strict continuation, attainable targets, and
policy comparisons are still required before interpreting any of these
observations as premature stopping or a default defect.

The recorder keeps returned points distinct from best sampled points, which can
be rejected or infeasible. Its owned termination report preserves the available
native tests and evidence. It records initialization and published boundaries,
but does not reconstruct all internal trial stages or nested solver work.
Elapsed times are diagnostic only; suite processes ran concurrently and were not
isolated for timing comparisons.

## Verification and next work

Sixteen focused tests pass: 11 new fixture/recorder tests, the case-selection
test, the original Misra1a test, and three existing competitor checks. They
cover all 27 NIST certificates with printed-parameter rounding allowances,
derivatives at both starts and references, native precision, constraint
references, family partitions, minibatch gradient expectations, seed
reproducibility, non-finite diagnostics, fused callbacks, and a rejected trial
in a failed partial step. A quadratic trace matches ordinary Executor results
and authoritative counts.

Workspace all-target/all-feature clippy, Rust formatting, documentation
formatting/lint, data checksums, source/output hashes, local links, and case
list regeneration checks pass. Basin's solver code and public API were not
changed in this expansion.

The next design task is maintainer review of the [protocol](../protocol.md),
especially family weights, budgets, and the material reliability/work tradeoff.
The next implementation tasks are the remaining [coverage
gaps](../coverage.md#before-calibration), attainable target checks, and
recorder/solver wiring. This pilot supplies a broader foundation for that work;
it does not close steps 4–6.
